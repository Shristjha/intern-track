# 🚀 InternTrack – Internship Application Tracker

### Your Internship Journey, Organized in One Place!

🌐 **[LIVE DEMO – Visit InternTrack](PASTE_YOUR_VERCEL_URL_HERE)**

InternTrack is a web-based internship tracking dashboard designed to help students organize, manage, and monitor their internship applications in one place.

## ✨ Features

- 📊 **Dashboard:** View application statistics.
- 💼 **Applications:** Add and manage internship applications.
- 📋 **Kanban Board:** Track application progress.
- 📅 **Calendar:** Organize important dates.
- 📈 **Analytics:** Monitor your application journey.
- 🔔 **Notifications:** Stay updated.
- 📄 **Resume Manager:** Manage resume-related information.
- 👤 **Profile:** Manage your profile.

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🚀 Run Locally

```bash
git clone https://github.com/Shristjha/intern-track.git
cd intern-track
npm install
npm run dev
```
